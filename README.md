# ⌨️ SwiftType - Typing Speed Test

A modern and responsive typing speed test application built with **HTML, CSS, and JavaScript**. Test your typing speed, improve your accuracy, and challenge yourself with multiple difficulty levels through an intuitive and interactive interface.

## 🌟 Features

- ⚡ Real-time Words Per Minute (WPM) calculation
- 🎯 Live typing accuracy tracking
- ❌ Error counter
- ⏱️ 60-second countdown timer
- 📈 Instant performance summary
- 🔄 Restart test anytime
- 📝 Random typing passages
- 🎚️ Three difficulty levels
  - Easy
  - Medium
  - Hard
- 📱 Fully responsive design
- 🚀 Deployed with GitHub Pages

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Rishikesh777/Typing-Speed-Test.git
```

### Navigate to the project

```bash
cd Typing-Speed-Test
```

### Run

Simply open `index.html` in your browser.

No installation or dependencies required.
